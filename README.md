# 領収書名検索（端末内保存版）

名前・あだ名・特徴から領収書の宛名を検索し、ワンタップでコピーするスマホ向けアプリ。
**サーバーなし・データは端末内(IndexedDB)だけに保存**。オフラインでも動作（PWA）。1店舗・1台向け。

## 使い方
1. 公開URLをスマホで開く → iPhone: 共有ボタン → **ホーム画面に追加**（データが消えにくくなります）
2. 「顧客」→「＋顧客を追加」、または「取込」で文章・CSVから登録
3. 「検索」で名前の一部・読み・あだ名・会社・特徴を入力 → 領収書名をコピー
4. 月1回は「設定」→「バックアップを書き出す」（JSONファイル。機種変更・消失時は「戻す」）

## 仕様
- 検索: 全角半角・ひらがなカタカナ・大小文字を無視、前方/部分一致、読み、入力ミス、複数語(AND)。同点・僅差は「候補が複数」と警告し、勝手に1人へ確定しない
- 読み仮名: 日本語入力の変換前の読みを自動取得(修正可)。取込データは読み未設定(編集で追加)
- 領収書名は複数登録可・変更履歴を保存・過去の宛名でも検索可。複数ある場合は自動選択せず確認を促す
- 重複候補は警告のみ(自動統合しない)。削除はごみ箱から復元可
- コピー＆貼り付け: 「顧客を追加」の「文章から入力」(メモの文章→項目に自動入力)、「取込」「バックアップ復元」の「貼り付け」ボタン(許可されない端末は欄を長押しでペースト)。バックアップは「文字でコピー」→メモ等に保管→貼り付けて復元でき、ファイル保存が難しい端末でも使える
- 取込: 貼り付け文章/CSV/TXT(UTF-8・Shift_JIS)。登録前に必ず確認画面。写真OCR・Excelは未対応

## 制約(正直に)
- ブラウザのデータ削除、長期間未使用(iPhone Safariは非インストール時7日)、機種変更でデータが消える。バックアップ必須
- 端末間の同期なし／複数人での共有不可（複数人・複数店舗は別アプリ receipt-finder）
- 実機(iPhone/Android)での確認は未実施。開発環境のChromeで、登録・永続化・読み検索・取込・履歴・バックアップ復元・オフラインを確認済み

## 開発
静的ファイルのみ(ビルド不要)。`python3 -m http.server` で確認。`lib.js`(検索・解析)、`db.js`(IndexedDB)、`app.js`(画面)、`sw.js`(オフライン)。
